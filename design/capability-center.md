## 1 目标与边界

π agent 是本机 Agent 的操作工作台 用户的高频任务是选择项目和会话 观察执行证据 打开文件并继续对话。模型 技能 扩展和 MCP 是低频但高风险的资源管理任务 不得占用工作台的持续空间。

因此界面固定为两个互补空间：

```text
工作台 执行和证据
  左栏 工作区 会话 文件树 能力中心入口
  中栏 会话 执行流 输入控制
  右栏 文件或运行时 Inspector 按需打开

能力中心 配置和资源管理
  常规 模型 技能 扩展 MCP
```

能力中心不是第二个页面 也不是右侧 Inspector。它是覆盖工作台的 viewport 级 `dialog` 仅在用户主动管理资源时进入。Modal 内可以使用主从列表和详情 不得再堆叠浮动卡片。

## 3 视觉系统

本规范继承 `DESIGN.md` 和 `tokens.css` 已落地的冷白 电蓝 中性灰语义 token 不引入原型 CDN 或新色板。

| 项目 | 规则 |
| --- | --- |
| 色彩 | `primary` 只用于当前选择 主操作 焦点和运行中线索 绿色 黄色 红色只表达完成 注意 失败且必须搭配文字 |
| 字体 | Inter 或系统无衬线承担 UI 正文 IBM Plex Mono 只用于路径 模型 ID Token 命令与代码 |
| 密度 | 4px 8px 节奏 列表行 40px 至 48px 模态内容区按 16px 至 24px 分组 |
| 形状 | 按钮和输入 6px 普通容器 8px Composer 和图片预览 12px 仅状态 chip 可胶囊化 |
| 深度 | 工作台平面化 Modal 下拉和抽屉可用一层低对比阴影 卡片不以阴影区分优先级 |
| 动效 | 150ms 至 250ms 只用于开关 选中 保存结果和抽屉位移 遵守减少动效偏好 |

禁止将高饱和蓝铺满面板 禁止所有容器都使用圆角卡片 禁止只用色点表达服务状态 禁止将 10px 灰字作为关键说明。

## 4 工作台布局

### 桌面 `>= 1100px`

- 左栏恒为 256px 上部依次是工作区选择 新会话 会话搜索 会话列表 下部为文件树和能力中心入口
- 中栏最小宽度 560px 消息正文最大宽度 860px 工具输出可延展至中栏宽度
- 右侧 Inspector 最大 540px 只在打开文件或查看当前会话运行信息时出现
- Inspector 打开后中栏保留输入控制和足够的消息阅读宽度 不能缩成窄列

### 平板 `760px 至 1099px`

- 左栏可收起
- Inspector 以覆盖层打开 不压缩消息列
- 能力中心采用全视口对话框

### 手机 `< 760px`

- 左栏和 Inspector 都是独立抽屉
- 能力中心全屏显示 横向 Tab 改为可滚动页签或侧栏导航
- 所有图标操作提供 40px 触摸目标 Composer 和停止动作始终可达

## 5 能力中心 Modal

### 外壳

| 区域 | 内容与行为 |
| --- | --- |
| 触发 | 左栏单一能力中心入口 快捷入口可直接打开指定 Tab 但不再渲染多个互相独立抽屉 |
| 桌面尺寸 | `min(1180px, calc(100vw - 64px))` 宽 `min(860px, calc(100vh - 48px))` 高 |
| 顶栏 | 标题 当前项目和作用域 摘要状态 全屏切换和关闭按钮 不显示假 Daemon 地址 |
| Tab 栏 | 常规 模型 技能 扩展 MCP 使用图标加文字 数量只来自已加载资源 |
| 内容区 | 独立滚动 标题和保存栏固定 主从页使用左 280px 列表和右侧详情 |
| 底栏 | 仅可写配置有脏数据时出现 显示目标路径 变更数量 放弃和保存并应用 |
| 离开 | Esc 遮罩 关闭按钮均有效 存在草稿时改为继续编辑或放弃变更确认 |

Modal 必须使用原生 `dialog` 或 portal 到 `body` 不能放在裁剪滚动容器内。打开时锁定背景滚动 捕获焦点 关闭后将焦点还给触发按钮。

### 作用域模型

| 类型 | 真实归属 | 保存语义 |
| --- | --- | --- |
| 浏览器偏好 | localStorage | 立即生效 不出现保存栏 |
| 当前会话控制 | `.jsonl` 会话状态 | 立即生效 失败后回滚 |
| 全局资源 | `~/.pi/agent` | 草稿确认后原子写入 明确显示路径 |
| 项目资源 | 当前项目 `.pi` 或 `.agents` | 草稿确认后原子写入 未受信任项目不得启用可执行资源 |
| 当前运行时 | 当前 `AgentSession` | 只读 Inspector 不伪装为持久配置 |

## 6 Tab 规格

### 常规

- 主题 跟随系统 浅色 深色 和完成提示音立即写浏览器偏好
- 提供减少动效偏好
- 显示本机绑定和当前项目根目录 不将本地进程描述为远程服务连接

### 模型

- 左侧支持 Provider 分组 搜索 当前会话模型和默认模型标识
- 右侧展示名称 ID Provider 文本或图片输入能力 支持的思考等级 上下文和成本只在真实数据存在时显示
- 选择用于当前会话时立即调用现有 `set_model` 失败保持原模型并显示恢复动作
- 配置编辑与会话切换分离 配置页必须区分全局或项目作用域 并在保存前提供 diff
- 密钥永不回显 只能覆盖写入 推荐环境变量引用 并避免复制原型中预填密钥的做法

### 技能

- 左侧按名称 搜索 来源范围和启用状态索引
- 右侧显示 `SKILL.md` 描述 路径 来源 允许模型调用开关和重新加载影响
- 打开文件只允许受信任根目录内的路径
- 新建技能先限制在项目 `.agents/skills` 目录 生成模板后重新解析 不提供未受控的全局文件写入

### 扩展

- 使用 Pi 的正式术语 扩展 页面副标题可写插件
- 先显示静态发现的来源 路径 作用域 注册工具 命令和加载诊断
- 禁用和启用显示可信状态与重载影响 项目级扩展是可执行代码 必须有二次确认
- 不以读取清单为理由执行未知 TypeScript 不在首版提供 npm Git 一键安装

### MCP

- MCP 不是 Pi SDK 原生能力 只有 `McpBridge` 扩展契约实现后才开放完整管理
- 接入后显示服务名 传输类型 状态 工具数 最近错误和最近测试时间
- 添加或修改服务时环境变量默认脱敏 测试连接只在用户显式点击后运行
- 未接入 Bridge 时不渲染假服务器卡片 可显示说明性空态和接入要求

## 7 共有状态与可访问性

每一项异步资源都必须有 skeleton 加载 空态 错误态 可恢复动作 禁用态和成功反馈。重要状态同时用文本与色彩表达。

- Tab 使用 `tablist` `tab` `tabpanel` 语义 方向键可切换
- 图标按钮有 `aria-label` 和 tooltip
- 焦点环始终可见 最小正文 12px 重要文本满足 WCAG AA 对比
- 保存失败保留草稿并指出字段和目标路径
- 启用 扩展 MCP 测试 删除和覆盖凭证等高风险操作必须在动作前说明范围

| `CapabilityCenterModal` | dialog 生命周期 作用域 脏状态和底部保存栏 |
| `CapabilityCenterTabs` | Tab 导航 数量和键盘语义 |
| `GeneralSettingsPanel` | 浏览器偏好 |
| `ModelsPanel` `ModelList` `ModelDetail` | 模型目录 会话切换和受控配置编辑 |
| `SkillsPanel` `SkillList` `SkillDetail` | 技能索引 详情和开关草稿 |
| `ExtensionsPanel` | 扩展注册表 可信状态和诊断 |
| `McpPanel` | Bridge 服务器管理和显式连通性测试 |
| `RuntimeInfoDrawer` | 保持当前会话只读证据 不与能力中心重复 |

实施时每个组件只能使用 `tokens.css` 的语义变量。不得从 `design/reference` 导入 HTML CSS 字体或运行时代码。
