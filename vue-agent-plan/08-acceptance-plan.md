验证里程碑 A 的会话切换 流式消息 工具调用展示 停止与历史恢复在新旧会话数据下均可稳定工作

| 层级 | 边界 | 验收标准 |
|---|---|---|
| 单元 | 图片兼容 流式 reducer 事件过滤 会话分支上下文 | 旧版与新版持久化数据均可安全归一化 |
| 单元 | SSE 连接状态机 | 重连 关闭 超时与旧连接事件不污染当前会话 |
| 集成 | chat store 会话切换 | 多个异步加载只有最后选择的会话可以提交消息列表 |
| 浏览器 | 新旧会话连续切换 | URL 当前会话详情 API 与渲染消息数量一致 |
| 浏览器 | 流式 工具 停止 刷新 | Step A 冒烟链路可完成且没有控制台错误 |
